# Mission: Web Foundations → D3 → React for Data Visualization

## Why

To build impressive, interactive data visualizations that demonstrate technical capability to my employer — and eventually publish them as portfolio pieces in blog posts. I'm following the React Graph Gallery course, which teaches HTML, CSS, JavaScript, D3, and React in that order; lessons here should track and reinforce that sequence.

## Success looks like

- Write JavaScript confidently enough to follow D3 documentation and examples without getting stuck on syntax
- Build at least one D3 chart from scratch that uses real data and could be shown in a professional context
- Publish a data visualization to a portfolio or blog post that demonstrates D3 skills to employers

## Constraints

- Complete beginner: no prior JavaScript experience
- Self-paced: ~30–60 minutes per day
- Follow the course order: HTML → CSS → JavaScript → D3 → React (+ D3)
- Each topic should stay focused on what data visualization actually needs

## Out of scope

- Full-stack JavaScript (Node.js, servers, databases)
- Frameworks other than React
- TypeScript
