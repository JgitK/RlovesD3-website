# Teaching notes

- The user learns best through **analogies** and **by doing**. Pair every concept with an analogy and a hands-on task.
- **Avoid analogy word collisions.** Calling `<main>` the "letter body" produced a second `<body>` tag (record 0007). Pick analogy words that aren't also HTML/JS keywords.
- The current analogy for page structure is the **house**: mailbox paperwork = head, house = body, porch = header, living room = main, back yard = footer.
- The user often resumes after a gap of several days. Open each session with a short from-memory retrieval check before new material.
- Visual feedback (colored blocks, Inspect) works better than verbal correction for structure mistakes.
