# Resources

## JavaScript

- [MDN Web Docs — JavaScript](https://developer.mozilla.org/en-US/docs/Web/JavaScript/Guide) — The authoritative reference for JavaScript. Use for verifying syntax and behavior. Trust level: high.
- [javascript.info](https://javascript.info) — The best free beginner JavaScript textbook. Deep explanations, good exercises. Trust level: high.

## D3

- [D3.js Official Docs](https://d3js.org) — Primary reference for D3. Trust level: high.
- [Observable / D3 Examples](https://observablehq.com/@d3/gallery) — Gallery of real D3 charts with source code. Useful for seeing how JavaScript concepts map to actual visualizations. Trust level: high.
- [React Graph Gallery](https://www.react-graph-gallery.com) — The course the user is currently taking. Covers D3 with a D3-first approach. Trust level: high (source material).

## HTML & CSS

- [MDN: What is CSS?](https://developer.mozilla.org/en-US/docs/Learn_web_development/Core/Styling_basics/What_is_CSS) — Rule anatomy and how the browser applies styles. Trust level: high.
- [MDN: Structuring documents](https://developer.mozilla.org/en-US/docs/Learn_web_development/Core/Structuring_content/Structuring_documents) — Page landmarks (header/nav/main/footer). Trust level: high.
