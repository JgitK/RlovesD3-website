Lesson 1

Variables & Data Types

Mission: Build D3 data visualizations for your portfolio & to impress your company

Why this matters for D3

Every D3 chart starts with data — a collection of numbers, names, and dates. Before you can tell D3 "draw a bar for each of these numbers," you need to know how JavaScript stores and categorizes values.

That's what this lesson is about. By the end you'll know how to declare variables and recognize the five primitive data types. This is the smallest possible step — but everything else builds on it.

Tip: Every code block below is editable and runnable. Change the values, break things, and observe what happens. That's the fastest way to learn.

Variables: const and let

A variable is a named container that holds a value. You create one with the keyword const or let, followed by a name, an =, and a value.

const — the default

Use const for any value you don't intend to reassign. In D3 code you'll see const everywhere — for datasets, scales, and chart elements.

Example
const city = "Chicago";
const population = 2700000;

console.log(city);        // Chicago
console.log(population);  // 2700000

let — when you need to reassign

Use let only when the value needs to change later. A common case is a running total or a loop counter.

Never use var. You'll see it in older JavaScript code. It works differently and causes subtle bugs. Stick to const and let.

Naming rules

  • Names are case-sensitive: population and Population are different variables.
  • Use camelCase by convention: chartWidth, countryName, gdpPerCapita.
  • Names can't start with a number or contain spaces.

Primitive Data Types

Every value in JavaScript has a type. The type determines what you can do with the value. For D3, you'll mainly work with three: strings, numbers, and booleans.

String — text

Any piece of text. In D3, strings are your labels: country names, categories, axis tick text. Wrap them in single quotes, double quotes, or backticks.

Strings
const country = "France";
const unit     = 'million';
const label    = `Population in ${country}`;  // template literal

console.log(label);  // Population in France

The backtick version (template literal) lets you embed variables with ${variable} — very useful when building D3 tooltips and labels.

Number — numeric values

Numbers are what you visualize. Bar heights, circle radii, axis ticks — all numbers. Unlike some languages, JavaScript has just one number type for both integers and decimals.

Numbers
const gdp      = 3000000000000;  // 3 trillion
const latitude  = 48.8566;          // Paris latitude
const yearDelta = gdp * 0.03;        // arithmetic works directly

console.log(yearDelta);

Boolean — true or false

A boolean has exactly two possible values: true or false. In D3 you'll use booleans to filter datasets — for example, show only countries where isEU is true.

Booleans
const isEU      = true;
const isVisible = false;

console.log(isEU);           // true
console.log(67 > 50);        // true  — comparisons return booleans
console.log(47 > 50);        // false

null and undefined — "nothing"

JavaScript has two ways to represent the absence of a value. You'll encounter them when working with real datasets that have missing values.

  • undefined — variable declared but never assigned a value
  • null — value explicitly set to "nothing"

What you learned

  • Use const by default; let only when you need to reassign.
  • The five primitive types: string, number, boolean, null, undefined.
  • Use typeof to inspect any value's type (typeof null === "object" is a quirk).
  • Template literals (`text ${variable}`) embed variables inside strings — essential for D3 labels.
  • In D3, CSV data arrives as strings — you'll need to convert numbers explicitly.
