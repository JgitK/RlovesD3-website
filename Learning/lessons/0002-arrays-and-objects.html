Lesson 2

Arrays & Objects

Mission: Build D3 data visualizations for your portfolio & to impress your company

The shape of D3 data

Every D3 chart needs data. That data almost always looks like this:

Typical D3 dataset
const data = [
  { country: "France",  population: 67 },
  { country: "Germany", population: 83 },
  { country: "Spain",   population: 47 },
];

That structure has a name: an array of objects. This lesson breaks it down — first arrays, then objects, then the combination that powers every D3 chart you'll ever build.

Arrays

An array is an ordered list of values. You create one with square brackets [], with items separated by commas.

Creating arrays
const populations = [67, 83, 47, 38];
const countries   = ["France", "Germany", "Spain", "Poland"];
const mixed       = ["Paris", 67, true]; // arrays can hold any type

Zero-based indexing

Each item in an array has a position called its index. Indexes start at 0, not 1 — this trips everyone up at first.

Objects

An object groups related values under named keys. Where an array uses numbered positions, an object uses names. You create one with curly braces {}.

Creating an object
const france = {
  country:    "France",
  population: 67,
  isEU:       true,
};

Each line is a key-value pair: the key (left of :) is the name, the value (right) is the data.

Arrays of objects — the D3 pattern

What you learned

  • Arrays are ordered lists created with []. Items are accessed by index, starting at 0.
  • .length, .includes(), .indexOf(), .join() are your most-used array tools.
  • Objects are collections of named properties created with {}. Use dot notation (d.key) to read them.
  • An array of objects is the standard D3 data format — one object per data point, one key per column.
  • The pattern data[i].key gets you any value in any dataset.
